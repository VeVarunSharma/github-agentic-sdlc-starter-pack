# Product intent

**Owner:** Product maintainers
**Status:** Active
**Last verified:** 2026-08-09

The starter pack demonstrates a reviewable, secure, progressively disclosed
agentic SDLC on GitHub. A team can adopt the repository, understand its control
boundaries, run one local validation command, and deploy the sample workload to
Azure without long-lived cloud credentials.

## Outcomes

- Agents receive a concise map and load task-specific knowledge on demand.
- Humans can review every instruction, agent, hook, MCP reference, and gate.
- Deterministic checks catch stale context before model behavior depends on it.
- The sample app proves the path from issue through guarded deployment.

## Non-goals

- Replacing human approval for security, merge, or production deployment.
- Shipping enterprise overlays, organization plugins, or team-managed settings.
- Providing a general agent framework or changing the Layer 3 sample runtime.
- Treating historical spikes as evergreen documentation.
