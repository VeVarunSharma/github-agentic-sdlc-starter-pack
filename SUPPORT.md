# Support

Thanks for using the **GitHub Agentic SDLC Starter Pack**!

This is a community-maintained reference template, not a Microsoft- or
GitHub-supported product. Please use the right channel for your
question:

| Channel | Use it for |
| --- | --- |
| 💬 [GitHub Discussions](../../discussions) | "How do I…?" questions, design discussions, show-and-tell, sharing your adoption story. **Try this first.** |
| 🐛 [Bug report issue](../../issues/new?template=bug.yml) | Reproducible defect in the template, infra, workflows, or scripts. |
| 💡 [Feature request issue](../../issues/new?template=feature.yml) | Concrete enhancement proposal. |
| 📋 [Spec issue](../../issues/new?template=spec.yml) | A unit of work an AI agent (or human) can pick up end-to-end. |
| 🛡️ [Private security advisory](../../security/advisories/new) | **Vulnerabilities — do not file as a public issue.** |
| 📚 [Microsoft Learn — App Service](https://learn.microsoft.com/azure/app-service/) | Azure App Service / OIDC deployment reference. |
| 🤖 [GitHub Copilot docs](https://docs.github.com/copilot) | Copilot coding agent, chat, instructions, and MCP. |

## What we will help with

- Setup problems following the README, `docs/adoption-playbook.md`,
  or `docs/azure-oidc-setup.md`
- Template behaviour (workflows, rulesets, APM gates) not matching
  what's documented
- Enhancement ideas that broaden the value for orgs adopting an
  agentic SDLC on GitHub
- Sharing variants you'd like upstreamed under `examples/`

## What we cannot help with

- Production incidents in your downstream deployment — escalate to
  Azure Support / your SRE team
- Help with arbitrary application code that has diverged from the
  sample app — please open an issue in your own repo
- Custom enterprise contracts, licensing questions for upstream
  dependencies — go to those vendors directly
- Anything that requires access to your private subscriptions or
  tenants — we cannot accept credentials

## Response expectations

This project is maintained on a best-effort basis. We aim for:

- Acknowledgement of issues / discussions within **5 business days**
- Triage decision (accept / decline / needs-info) within **10 business days**
- Security findings: see [`SECURITY.md`](./SECURITY.md) for stricter SLAs

If a thread has been quiet for a while and you need movement, a
polite ping with new context is welcome.
